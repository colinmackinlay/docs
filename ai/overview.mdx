The AI Tools module provides a set of experimental tools for demonstrating and exploring AI capabilities with school staff. They are designed to remove the friction of needing separate commercial accounts — so you can show staff what AI can do directly from within Clever School Systems, without requiring anyone to sign up for an external service.

<Tip>
  These tools are experimental and intended for demonstration and exploration. They are not yet production features, and behaviour may change as development continues.
</Tip>

## What's Available

Currently, the image generation tool is enabled. Use it to demonstrate AI image generation to staff in a familiar, low-barrier environment. Additional tools are under active development and will be released over time.

## Image Generation

Generate images directly from within Clever School Systems using the image generation tool. Enter a prompt, and the tool produces an AI-generated image without any need for a Midjourney, DALL-E, or other external account. This makes it straightforward to run AI demonstration sessions with staff — no account setup, no subscription, no friction.

<Info>
  Additional AI tools will be added over time. Watch the release notes or contact [support@cleverschool.systems](mailto:support@cleverschool.systems) for the latest updates on what's coming.
</Info>
